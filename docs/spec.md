# Soyoli 仕様

もとは pen.dev のデザインファイル `untitled.pen`（画面 16 枚 + 共通コンポーネント 4 種）から起こした仕様。
**実装済みの部分は実装に合わせてある**（実装とデザインが食い違う箇所は実装が正）。実装しないと決めた案（音声プロファイル、作品ごとの設定、先読み、取得状態つきの目次など）は載せていない。

## 1. 概要

日本語の小説を **読む** と **聴く（端末の音声合成による読み上げ）** の両方で楽しむモバイルアプリ。

- 対応ソース: **ファイル**（EPUB・PDF の取り込み）と **Web 小説**（小説家になろう / カクヨム / ハーメルン / pixiv）
- 読み上げは端末内蔵の音声を使う。画面を消しても、アプリを閉じても（バックグラウンドでも）読み続ける
- 日本語読み上げ特有の課題（難読語・会話文の聞き分け）を、**読み方辞書** と **カッコ別の音声** で解決する

## 2. 基本概念

| 用語 | 意味 |
| --- | --- |
| 作品 | 本棚の 1 冊。取り込んだファイル 1 つ、または Web 小説 1 作品 |
| 話 | 作品内の区切り。Web 小説の「第48話」も、EPUB の章（「六、銀河ステーション」）も、PDF の 10 ページごとのまとまりも、画面では「話」と呼ぶ |
| 段落 | 読み上げとハイライトの最小単位。本文の改行とブロックの区切りで切り、文の途中や文末では切らない。1000 文字を超える段落は、読み上げエンジンの上限のため 1000 文字ごとに分けて読む（表示は 1 つの段落のまま） |
| 読み上げ位置 | ビューアーとプレイヤーが共有する位置。話と、その中の段落の番号で持ち、作品ごとに保存する |
| 読み方辞書 | 「表記 → 読み」の置換ルール。名前を付けた辞書（作品ごとに 1 つ選ぶ。複数の作品で共有できる）、すべての作品に効く辞書、アプリ組み込みのシステム辞書の 3 種類（§4.6） |

**読む画面と聴く画面は分けない。** 作品を開くと、本文と常設プレイヤーを同じビューアーに表示する。話送り・目次・再生による話の移動は本文にも反映し、開き直したときは保存した読み上げ位置に戻る。作品を開くだけでは再生を開始しない。

## 3. 画面構成とナビゲーション

### タブ（下部固定）

左から次の順に並べる。起動時は本棚を開く。

| タブ | アイコン | 内容 |
| --- | --- | --- |
| ホーム | home | 作品を探す・追加する（URL の入力、対応サイト、ファイルの取り込み）。アプリ内ブラウザもこのタブの中で開く |
| 本棚 | library | 作品一覧と閲覧履歴 |
| 設定 | settings | アプリ全体の設定 |

開いているタブをもう一度押すと、そのタブの最初の画面に戻る（ブラウザや設定の各ページを閉じる）。

### ミニプレイヤー（タブバーの上に常駐）

- サムネイル（ファイルの作品は表紙、Web 小説はサイトのアイコン。どちらも無ければ記号）・作品名・話名・再生／一時停止（ボタンはこの1つだけ。段落や話の移動はビューアーで行う）
- タップで再生中の作品のビューアーを開く。ボタン以外はバーのどこを押しても開く（端や、ボタンのまわりの余白も含む）。独立したプレイヤー画面は設けない。
- 起動時は、前回最後に開いていた作品を一時停止の状態で戻す
- 閉じるボタンは置かない。本棚タブのメニューで「本棚から削除」した作品がミニプレイヤーの作品なら、読み上げを止めてミニプレイヤーも消す（読んでいた位置は残る）。リーダーのヘッダーで本棚から外したとき・履歴から削除したときは消さない

## 4. 画面別仕様

### 4.1 本棚

デザインの案（件数サマリー、ソース・状態の絞り込み、追加ボタン、続きから）は使わず、次の形にする。

- **ヘッダー**: タイトル「本棚」と検索ボタン
- **検索**: 検索ボタンを押すと、タイトルの下に入力欄を出す。入れた言葉を書名か著者に含む作品だけを、本棚と履歴の両方で残す。空白で区切ると、すべての言葉を含む作品だけになる。全角と半角、大文字と小文字、ひらがなとカタカナは区別しない。合う作品がなければ「見つかりませんでした」と出す。ボタンをもう一度押すと欄を閉じ、言葉も消える。並べ替えは設けない
- **切り替え**: 「本棚 / 履歴」の 2 択。件数は出さない。ソースや状態での絞り込みは設けない（Web 小説はサイトで分けない）
- 作品の追加はホームで行う。本棚に追加ボタンは置かない
- **ファイルの取り込み**（ホーム「ファイルを取り込む」）:
  - OS のファイル選択で選んだファイル（複数可）を 1 つずつ順に読み、アプリの領域に複製して本棚に残す。起動をまたいで残る。本棚では選んだ順に先頭へ並ぶ
  - 画面の文言は形式名（EPUB）を出さず「ファイル」とする。例外として、ホームの「ファイルを取り込む」の行にだけ、選べるファイルが分かるよう「対応形式：.epub / .pdf（複数選べます）」と拡張子を出す。対応形式は EPUB と PDF で、形式は拡張子、拡張子が無ければ中身で判別する
  - 本棚には書名・著者・表紙・シリーズ（名前と巻）だけを持ち、本文は作品を開いたときにファイルから読む
  - 同じ名前のファイルを取り込み直すと、保存済みのものを置き換える。読んでいた位置は引き継ぐ
  - **PDF（最小実装）**:
    - 本文は端末の仕組みで抜き出す（iOS は PDFKit、Android は PdfBox-Android。アプリ内のモジュール `modules/pdf-text`）。このモジュールを含まない古いビルドでは取り込めず、その旨を伝える
    - 取り込み時に読むのはページ数・書名・著者と、表紙にする 1 ページ目の画像（横 600px の JPEG）だけ。書名が無ければファイル名を書名にする。表紙は取り込み時に一度だけ作って端末に保存し、描けなければ表紙なしで取り込む
    - 話は 10 ページごとに分け、題名は「p.1–10」のようにページの範囲にする。PDF の目次（しおり）はまだ使わない
    - 本文は話を開いたとき、または読み上げがその話へ進んだときに、その話のページだけを抜き出す（Web 小説の話の取得と同じ流れ）。抜き出した本文は保存しない
    - 抜き出した行は段落にまとめる。ページの折り返しはつなぎ（ページをまたぐ段落も）、短く終わった行・字下げ・カッコで始まる行で段落を切る。ページの最初と最後にあるページ番号と、半分以上のページで繰り返す柱は外す
    - 文字の情報が無いファイル（スキャンした画像）とパスワードが付いたファイルは、取り込み時に理由を伝えて断る。大きさは 64 MB まで
    - 本文の無いページだけの話は、本文のない話として扱う（読み上げは飛ばす）
    - **対応していないもの**: ルビの取り除き（文字の大きさが要る）、段組み・表の読み順、目次での話分け、元のファイルの表示
- **本棚**: 取り込んだファイルと、「本棚に追加」した Web 小説。最近開いた順
  - ビューアーで開いた作品が先頭に来る。新しく取り込んだ・追加した作品も先頭。話の本文が届いただけでは動かない
  - 並び（作品 ID の順）と、各作品を最後に開いた時刻を保存し、起動時に戻す。並びは保存した順そのもの
  - 表示はグリッド（3 列）とリストを切り替えられる。選んだ表示は次回も同じ
  - グリッド: 表紙、書名、著者、読んでいる話の題名。著者と話の題名は別の行に出し、同じ位置には入れない（話の題名は、読みかけの話がある Web 小説だけ）
  - リスト: 小さな表紙、書名、「著者 · ソース」、読んでいる話の題名
  - **巻のまとまり**: 取り込んだファイルの作品のうち、同じ作品の別の巻は 1 つにまとめて出す
    - 同じ作品かどうかは、EPUB が自分で名乗るシリーズの名前だけで決める。書名からは推測しない（書名だけでは、別の作品を巻と取り違える）。名前の全角と半角、大文字と小文字、空白は区別しない
    - シリーズの情報は、EPUB 3 の `belongs-to-collection`（種類が `series` か、種類の指定がないもの。巻は `group-position`）を先に見て、なければ Calibre の `calibre:series` と `calibre:series_index` を見る。取り込み時に読んで、書名・著者と一緒に持つ
    - シリーズを名乗らない EPUB と PDF はまとめない。まとめるのは 2 冊以上あるときだけ。Web 小説はまとめない
    - シリーズを読むようになる前に取り込んだ作品は、次に開いたときにファイルから読み直して覚える（取り込み直しても同じ）
    - まとまりそのものは保存しない。本棚を出すたびに各巻のシリーズから作るので、巻を足す・消すとそのまま変わる
    - 本棚では、表紙（最後に開いた巻のもの）、シリーズの名前、著者（最後に開いた巻のもの）を出す。位置は、最後に開いた巻の位置
    - 単体の作品と形で見分けられるように、表紙は後ろに無地の面を 2 枚ずらして重ね、束に見せる（全体の大きさは単体の表紙と同じ）。グリッドでは表紙の右上に重なりのアイコンと冊数を出し、表紙の下の行は単体と同じ（書名・著者）。リストでは小さな表紙を同じく重ね、冊数は「著者 · 3冊」の行に出す
    - 押すと、本棚のページがその作品の巻の一覧に切り替わる（タブとミニプレイヤーは残る）。巻の順（番号のない巻は後ろ）に並べ、表示は本棚と同じグリッド／リスト。戻るボタン、Android の「戻る」、本棚タブをもう一度押すと本棚に戻る。戻ったとき、本棚はスクロールしていた位置のまま
    - 開く・長押しメニュー・削除は、巻の一覧の中で 1 冊ずつ行う。まとまり自体に長押しメニューはない。削除して 1 冊になった作品は、ふつうの作品として本棚に戻る
    - 検索は巻ごとに書名と著者を見て、合った巻だけをまとめ直す
- **履歴**: ビューアーで開いた Web 小説。本棚に追加していない作品も載る。EPUB は対象外
  - 1 作品 1 行。読み直すと先頭に移り、最後に読んだ話と日時を上書きする
  - 新しい順のリストで、日ごと（今日 / 昨日 / 日付）にまとめる。各行は書名と「ソース · 最後に読んだ話」
  - 本棚に無い作品の行には「本棚に追加」ボタン、ある作品には「本棚にあります」
  - 100 作品まで。超えた分は古いものから消える
  - 保存するのは作品のメタ情報・最後に読んだ話・日時だけ。本文と目次は保存しない
- **長押しメニュー**（シート）: 書名の下に作品の情報を「ラベル／値」の表で出し、その下に操作を並べる。表の行は著者・サイト・読んでいる話・URL（ファイルから取り込んだ作品は著者だけ）。URL の行を押すとコピーする
  - 本棚の作品: 元のサイトで開く（Web 小説）／本棚から削除（取り込んだファイルの作品は確認のうえ、ファイルごと端末から削除する）
  - 履歴の行: 本棚に追加または本棚から削除／元のサイトで開く／履歴から削除
- **履歴のメニュー**（「…」）: すべての履歴を削除（確認あり）。本棚と読書位置は消さない
- 本棚から外しても履歴には残る。履歴から消しても本棚には残る

### 4.2 リーダー（リーダービュー案を採用）

本文とプレイヤーを同時に表示する画面。下から出るモーダルで開き、閉じると元の画面（本棚など）に戻る。ファイルの作品と Web 小説で同じデータ形式・同じビューアーを使う。

- **ヘッダー**（左から）:
  - 閉じる（chevron-down）と題名。矢印と題名は 1 つのボタンで、どちらを押しても閉じる。題名は作品名（小さく上）と話名（下）
  - 本棚に追加／本棚から削除（ブックマーク。Web 小説だけ。ファイルの作品は常に本棚にある）
  - 目次（list）、リーダー設定（type）、その他（…）
- **その他（…）メニュー**: 読み方辞書（§4.6）。Web 小説には、元のサイトで開く／再取得（読んでいる話と目次を取り直す）／URLをコピー も出す
- **本文**: 縦スクロールの横書き。読み上げ状態に応じて段落を 3 段階で表示する
  - 読み終えた段落: 淡色
  - 読み上げ中の段落: マーカー色の背景（黒のテーマでは半透明の蛍光イエロー #F2FF4D・不透明度 30%）。文字の色は変えない
  - 次の段落: 通常色
  - 見出しは太字で一回り大きく（1.2 倍）する。Web 小説は、話の題名を見出しとして本文の先頭に置く（読み上げもする）
  - ルビは親文字の上に表示する。傍点として付けられたルビ（・など）は読みとして扱わない。挿絵は本文の中に表示する
- **話を移ったとき**（前の話／次の話、目次、読み上げが次の話へ進んだとき）: 題名と読む位置はすぐ変わり、本文の位置には読み込み中の印を出す。本文はその後で組む。長い話でも、ボタンを押してから何も変わらない時間を作らない
- **読み込み中の表示**: どこでも同じ部品（`components/Loading`）で出す。回る印を中央に置き、文言があればその下に添える。行の中では横に並べる（音声の読み込み）
  - 作品を開いている間（ファイルの読み込みと、再生の準備）は、ビューアーと同じ場所に閉じるボタンを置き、「読み込み中…」と出す。読み込みが終わるまで見た目は変わらない
  - 本文を組んでいる間は印だけ、話を取得している間は「次の話を取得しています…」を添える
- **本文がまだ無い話**（取得前の Web 小説の話、読み出し前の PDF のページ）: 取得中は「次の話を取得しています…」、失敗したら「本文を取得できませんでした。」を本文の位置に出す
- **プレイヤー**（画面下部に常設、§4.7）: 停止中・一時停止中も本文と同時に表示する
- **リーダー設定**（シート）: 選んだ内容は保存し、次回も同じ
  - 文字サイズ: 小（14pt）／中（17pt、初期値）／大（21pt）／特大（25pt）
  - 行間: 狭い／標準（初期値）／広い
  - テーマカラー: 黒（初期値）／セピア／白。変わるのは本文の領域だけで、ヘッダーやプレイヤーはアプリの配色のまま
  - 本文から再生: ダブルタップ（初期値）／タップ（§4.4）

### 4.3 （不採用）リーダー（読み上げ中）

pen.dev 上の「リーダー Reader (読み上げ中)」は使わない。この案にしかない次の要素は、リーダービューには置かない。

| 要素 | 扱い |
| --- | --- |
| ヘッダーのしおりボタン | なし（しおり機能は廃止） |
| ページ表示「48 / 112」 | 文字数ベースの進捗に置き換え |
| タイマーチップ・速度チップ | ビューアー内プレイヤーのボタンにする |
| 再生時間「第六章 12:04 / -17:52」 | なし（進捗は文字数で示す） |
| 文リストボタン | なし |

段落メニュー・追従解除（§4.4）、音声設定シート（§4.5）、辞書登録（§4.6）は、この不採用案の上に描かれている。どれもリーダービューの上で同じように使う。

### 4.4 段落のタップ・段落メニュー・追従解除

- **タップ**: リーダー設定の「本文から再生」で決まる
  - ダブルタップ（初期値）: 1 回のタップは読み上げ位置をその段落へ移すだけ（再生中なら、その段落から読み続ける）。同じ段落を続けてもう一度（0.3 秒以内に）タップすると、その段落から再生を始める
  - タップ: 1 回のタップで、その段落から再生する
- **追従（自動スクロール）**: 開いたときは追従する。読み上げ中の段落が見える位置へ自動でスクロールする
  - 手動でスクロールすると追従を止める。読み上げや読み上げ位置の更新は止めない
  - 追従を止めている間は、本文の下端に「読み上げ位置へ」ボタンを出す。押すと現在の読み上げ位置へスクロールし、追従に戻る（常設の ON／OFF ボタンは置かない）
  - 追従を止めた状態は話が切り替わっても保つ。その間に段落をタップしても、勝手に追従へ戻さない
- **長押し**: 段落メニュー（シート）を出す。その段落の本文と、**ここから読み上げ / 辞書登録 / コピー**。本文は一部を選択でき、選択していればその部分だけをコピーする。デザインにある「しおり」は廃止した

### 4.5 音声設定（シート）

- **速度**: 0.5〜3.0 倍のスライダー（0.1 刻み）と、よく使う値のボタン（0.7 / 1 / 1.2 / 1.5 / 1.7 / 2）。ボタンを押すとスライダーも動く。スライダーの両端に −／＋ ボタンがあり、押すたびに 0.1 ずつ変わる（下限・上限では押せない）
- **声の高さ**: 0.5〜2.0のスライダー（初期値「標準」= 1.0）と標準に戻すボタン。速度と同じく、スライダーの両端に 0.1 刻みの −／＋ ボタン
- **基本音声**: 端末で利用できる日本語音声から、セレクト（iOS はメニュー、Android はドロップダウン）で選ぶ
  - 「端末標準」は常に選べる。拡張音声は名前に「（拡張）」を付ける（SDK から取得できる場合のみ。性別・オフライン対応は推測しない）
  - 横の「試聴／停止」ボタンは選択中の声を鳴らす。別の声を選ぶと試聴は止まる。試聴は音声の選択や読み上げ位置を変更しない
  - 本文の再生中に試聴した場合は一時停止し、試聴後に自動再開しない
  - 読み込み中・取得失敗・日本語音声なしの表示と再取得に対応する
  - 音声の追加は端末の読み上げ設定で行うよう案内する
  - カッコ別の音声の「声」も同じ部品
- **カッコ別の音声** の行: 今の値（声を変えている種類の数、無ければ「オフ」）を表示する。押すとシートを閉じて、一覧のページを全画面で開く。閉じるとリーダーに戻る
- **置き場所の分け方**: 読み上げの設定は、設定タブ（§4.14）にすべてそろえ、このシートからも届くようにする。連続再生、前書き・後書き、ページをめくる音、画面を消さない設定は設定タブだけに置く
- 速度・音声・声の高さは同じボトムシート内に配置し、子シートへの導線は設けない。選択してもシートは閉じない
- 音声設定シートには追従スクロール・連続再生の設定項目を設けない
- 設定は全作品で共通で、保存して次回の起動でも使う。値を変えると、読んでいる段落をその設定で読み直す

### 4.6 辞書登録と読み方辞書

**辞書の構成**

- **名前を付けた辞書**: 作品は、使う辞書を 1 つ選ぶ（選ばなくてもよい）。1 つの辞書を複数の作品で使える（同じ作品の別サイト版、シリーズの各巻など）
- **すべての作品**: どの作品にも効く辞書
- **システム辞書**: アプリに組み込みの読み方（URL →「URL省略」、区切りの記号や罫線は読まない、伏せ字、笑いの「ｗｗｗ」など）。編集はできないが、1 件ずつオフにできる

**辞書登録**（全画面のページ。シートではない）

- 段落メニューの「辞書登録」から開くと、入力欄にその段落の本文が入った状態で始まる。登録したい語だけを残して使う
- 入力の種類: 文字列 ／ 正規表現（読みの中で `$1`、`$&` などが使える。正しくない正規表現は登録できない）
- 入力（表記）と読み（例: 小鳥遊 → たかなし）。読みを空にすると「読まない」
- 段落をまたいで一致: オンにすると話全体に対して照合し、複数の段落にまたがる範囲を置き換えられる
- 説明（任意）: 一覧で、入力の代わりに表示する
- 登録先の辞書: この作品の辞書（まだ無ければ、その場で作品名の辞書を作る）／ すべての作品
- 編集のときは「削除」も出す

**適用のルール**

- 優先順: **段落をまたぐルール → 作品の辞書 → ルビ → すべての作品 → システム辞書**。先に当たった部分は、後のルールでは置き換えない
- 同じ優先度の中では長い一致が優先。同じ長さなら先に登録したもの
- 保存後は **次に読み始める段落から** 反映する。表示中の本文は書き換えない（「小鳥遊」のまま）
- 読むものが残らない段落（区切りの記号だけの行など）は、読み上げで飛ばす

**登録した読みの一覧**

- リーダーの「その他（…）」メニューの「読み方辞書」で、その作品に適用される読みを見られる。上から「使う辞書」（押すと辞書の選択へ）、「この作品の読み」（作品が使う辞書の読みと「読みを追加」）、「すべての作品の読み」。行を押すと編集、スイッチで適用のオン・オフ。設定タブへ移らずに確認・修正できる
- 設定タブの「読み方辞書」には、システム辞書・すべての作品・名前を付けた各辞書が並ぶ。辞書のページでは、名前の変更、その辞書を使う作品の確認、読みの追加・編集・オン／オフ、辞書の削除（確認あり）ができる
- 作品に辞書を割り当てたとき、作品名と作品ページの URL も一緒に保存する。作品が本棚から消えたあとも、どの作品の辞書かが分かるようにするため

### 4.7 ビューアー内プレイヤー

- 独立した画面・モーダルではなく、本文の下部に常設する
- 本文を広く取るため、3 段に詰める
  - スクラバー: **読んでいる話の中** の位置（トラック 4px＋つまみ）。タップ・ドラッグで、離した位置の段落へ読み上げ位置を移す。再生中ならそこから読み続け、停止中は再生を始めない
  - 文字数: 「読んだ文字数 / 話の文字数 字」。本文のない話（取得中の話も）では「0 / 0 字」
  - 話数: 文字数と同じ行の右端に「何話目 / 全部の話の数 話」を出す（例: 左に「1,234 / 5,678 字」、右に「12 / 345 話」）。文字数は左端のまま。ファイルの作品は章の並びから数える。Web 小説は、作品全体の目次（カクヨム・ハーメルン・pixiv のシリーズ）か、話のページにある数（小説家になろうの「2/3」）から分かったときだけ出す。全部の数が分からなければ「12 話」、何話目かも分からなければ（目次を取得する前、短編）出さない。全部の数は保存しない（目次と同じ）ので、起動後に本棚から開いたときは、目次か本文が届いてから出る
  - 操作の行: タイマーボタン（左。残り時間を「28分」「話末」のように表示。オフのときは空）／前の話・再生／一時停止・次の話（中央）／音声設定ボタン（右。ラベルは再生速度「1.5×」）
- 段落単位の送りボタンは置かない（位置合わせはスクラバーと本文のタップで行う）
- 目次とリーダー設定はヘッダーのボタンから、タイマーと音声設定はプレイヤーのボタンから開く
- 読み上げに失敗したときは、プレイヤーの下に理由を出して停止する（もう一度再生を押せばやり直す）
- **連続再生**: 話の終わりまで読むと次の話へ進む。本文のない話は飛ばし、移動先の話をビューアーにも表示する。次の話の本文がまだ無ければ、取得できるまで待ってから読み始める。設定タブ（§4.14）の「連続再生」でオフにできる（初期値はオン）。オフのときは、話の最後の段落を読み終えたところで止まり、読み上げ位置は次の話の先頭に進む。読み上げ中に切り替えても、読んでいる段落はやり直さない
- **ページをめくる音**: 同じ作品の中で先の話へ移ったときに鳴らす。読み上げが自動で次の話へ進み、そのまま読み続けるときだけが対象（連続再生がオフ、またはタイマーで、話の終わりに止まるときは鳴らさない）。作品を開いたとき・起動時に前回の位置へ戻すとき・話送り・目次やスクラバーでの移動は鳴らさない。音量は読み上げより控えめ。読み上げ中は、音が鳴り終わって少し間（約0.25秒）を置いてから次の話を読み始める。アプリが画面に出ていない間（バックグラウンド・画面オフ）は、音の再生が終わった通知を受けてすぐ読み始め、この間は置かない（Android はその間アプリのタイマーを止めるため、タイマーで待つと読み上げが再開しない）。設定タブ（§4.14）の「ページをめくる音」でオン・オフできる（初期値はオン）。音のモジュールを含まない古いビルドでは鳴らない
- 話送り・目次では口絵など本文のない話も表示できる。その話では再生を無効にする
- **目次シート**: 開いたとき、読んでいる話が見えている範囲の中央に来る位置までスクロールして出す（開くたびに。開いている間は勝手に動かさない）。読んでいる話の行は一段明るく塗る。話名は1行で、長いものは末尾を省略する。Android では全画面の高さで開く（半分の高さでは一覧の中央が画面外になるため）
  - 小説家になろうは目次が 100 話ごとのページに分かれている。取得していないページは「前の100話」「次の100話」の行として出し、押すとその場で一覧に展開する（シートは閉じない）。話送りがその行に達したときも、取得して先へ進む
- **ロック画面・通知の操作**: 再生／一時停止、前の話、次の話、停止。話名・著者・作品名（表紙があれば表紙も）を表示する
- **読み上げ中は画面を消さない**: 設定タブ（§4.14）でオンにすると、読み上げている間だけ画面の自動消灯を止める（初期値はオフ）

### 4.8 スリープタイマー

- プレイヤーのタイマーボタンからシートを開く
- 選択肢: オフ / 5分 / 10分 / 20分 / 30分 / 60分 / この話の終わりまで。選ぶとシートを閉じる
- 時間になったら、**読んでいる段落が終わってから停止** する（段落の途中で切らない）。「この話の終わりまで」は、その話の最後の段落を読み終えたところで止まり、読み上げ位置は次の話の先頭に進む
- 残り時間はプレイヤーのタイマーボタンに分単位で出す
- 止まっている間に時間が来たら、タイマーを解除するだけ。タイマーは保存しない（アプリを終了するとオフに戻る）

### 4.9 次話の取得失敗

連続再生中に次の話を取得できないと、その話へ移ったところで読み上げを止め、本文の位置に「本文を取得できませんでした。」を出す。ビューアーの「その他（…）」→「再取得」でやり直せる。アラートは出さない。

### 4.10 ホームとアプリ内ブラウザ（Web 小説の検出）

- **ホーム**: 作品を探す・追加する入口をまとめる。本棚の中身は出さない
  - URL の入力欄: Web のアドレス（`https://` の有無は問わない）を入れると、アプリ内ブラウザで開く。キーワードでの検索はしない。アドレスでなければ「URLを入力してください。」と出す
  - 対応サイト: カクヨム・ハーメルン・pixiv。行を押すとサイトのトップを、「ランキング」ボタンでランキングを開く。行にはサイトのアイコンを出し、読み込めないときは地球のアイコンにする
  - ファイルから追加: 「ファイルを取り込む」（§4.1）。一度にいくつでも選べる。取り込んだ作品は本棚に入るだけで、ビューアーは開かない（読み上げ中の作品を止めない）
    - 取り込みの最中は、行に「読み込み中…（2 / 5）」と進み具合を出す
    - 終わると、ミニプレイヤーの上（ミニプレイヤーが無ければタブバーの上）に知らせを出す。どのタブにいても見える
      - 文言: 1 冊なら「『書名』を本棚に追加しました」、複数なら「3冊を本棚に追加しました」。読めないファイルがあれば「1件は読み込めませんでした」を添える
      - ボタン: 1 冊なら「開く」（その作品をビューアーで開く）、複数なら「本棚」（本棚タブへ移る）。どちらも知らせを閉じる
      - バツボタンで閉じる。作品が入っただけなら 6 秒で自分で消える。読めないファイルがあったときは、閉じるまで残る
    - 読めないファイルがあっても残りは取り込む。読めなかったファイルは、ホームの行の下に名前と理由を出す（次に取り込むまで残る）
- **アプリ内ブラウザ**: 戻る／進む、URL 表示（鍵アイコン）、再読み込み。Web ページ以外（`tel:` やほかのアプリへのリンク）は開かない。Web 版（ブラウザで動かす場合）では使えない
  - **置き場所（実装済み）**: ホームタブの中の画面として開く。全画面には重ねない。下のタブとミニプレイヤーは出たままで、ほかのタブへ切り替えて戻っても、開いていたページとスクロール位置はそのまま残る
  - 操作は上の1本のバーにまとめる（閉じる／戻る／進む／URL／再読み込み・中止）。下に専用のバーは置かない
  - 閉じるとホームの最初の画面に戻る。開いているタブをもう一度押したときも、そのタブの最初の画面に戻る（ブラウザを閉じる。設定タブの各ページも同じ）。最初の画面にいるときは、いちばん上までスクロールする
  - 本棚やリーダーの「元のサイトで開く」は、ホームタブに切り替えてそのページを開く
- **作品の検出**: 対応サイトの話のページを開くと、下部にカードを出す
  - 1 行目に話の題名（章の見出しがあれば「章 · 話」）、2 行目に「作品名 · 著者」
  - ブックマークのボタン（本棚に追加／本棚から削除）と「リーダーで開く」
  - 「リーダーで開く」は、開いている話からビューアーを開く。それだけでは本棚に入らず、履歴に載る
  - 目次はページを開いたときに一緒に取得しておき、ビューアーの目次と話送りに使う
- **ハーメルン**（`syosetu.org`、成人向けの `h.syosetu.org` も同じ）: 話のページ `/novel/<作品番号>/<話数>.html` を検出する。目次は作品ページ `/novel/<作品番号>/` の 1 ページに全話がある。サイトは端末によってスマホ向けと PC 向けの 2 種類のページを返すので、両方の構造を読む。1 話だけの作品（作品ページがそのまま本文）は、実物で未確認
- **pixiv**（`www.pixiv.net`）: 小説のページ `/novel/show.php?id=<小説の番号>` を検出する。作品はシリーズ（`pixiv-series-<シリーズの番号>`）で、シリーズに入っていない小説は 1 話だけの作品（`pixiv-novel-<小説の番号>`）になる
  - 本文はページの HTML に無い（ページが自分で描く）ので、ページが読んでいるのと同じ JSON（`/ajax/novel/<小説の番号>`）から読む。シリーズの目次も同じく `/ajax/novel/series/<シリーズの番号>/content_titles` から読む。どちらも公開された API ではなく、変わると読めなくなる
  - pixiv はページを読み込み直さずに小説から小説へ移るので、検出は読み込みの完了ではなく、アドレスが変わったことを合図にする（Android で確認する前提。iOS は実物で未確認）
  - 本文の記法: `[[rb:漢字 > かんじ]]` はルビ、`[chapter:見出し]` は見出し、`[newpage]` は区切り線にする。挿絵（`[pixivimage:…]`・`[uploadedimage:…]`）とページ移動（`[jump:…]`）は出さず、リンク（`[[jumpuri:題 > URL]]`）は題だけを残す
  - 年齢制限のある小説（R-18・R-18G）は、いまは検出しない（シリーズの途中にあれば、その話は「本文を取得できませんでした。」になる）。限定公開の小説（`/novel/unlisted/`）も扱わない
  - 規約との関係: pixiv のガイドラインは「クローラーなどのプログラムを使って作品を収集する行為」を禁じている。取得は開いた話と読み上げが進んだ話だけにし、本文も目次も保存せず、先読みもしない（§5）。この範囲を広げる前に、規約を確認し直すこと。名前とアイコンは pixiv へのリンクとしてだけ使い、加工しない。アプリを紹介するときは、pixiv が作成・配布しているアプリではないことを添える
- **成人向けサイト**: ノクターンノベルズ・ムーンライトノベルズ・ミッドナイトノベルズ（作品のページは 3 つとも `novel18.syosetu.com`）とハーメルン（R18、`h.syosetu.org`）の作品も、一般向けと同じように検出して読める。ホームには並べない（URL を入力するか、サイト内のリンクからたどって開く）。小説家になろうも同じく、検出と読み上げは残したままホームには並べない（ホームの「対応サイト」はカクヨム・ハーメルン・pixiv）。小説家になろうは、サイトの名前もアイコンもアプリのどこにも出さない（運営会社の商標ガイドラインが、事前の承諾のない商標の使用を原則として禁じている）: 表紙・本棚と履歴の行・作品のメニューはサイトの欄を省き、作品はアドレスで見分ける。年齢の確認はサイト自身のページが行い、アプリは代わりに答えない。そこでの回答（Cookie）は、あとから話を取得する通信にも共有する（iOS はアプリ内ブラウザの設定で共有、Android はもともと共有）。確認に答えていない状態で話を取得すると、読み込めないエラーになる

### 4.13 カッコ別の音声

デザインの案（音声プロファイルの割り当て、作品ごとの上書き）は使わない。

- **対象のカッコ**: 「」（会話）、『』（引用・強調）、（）（心の声。半角 ( ) も同じ扱い）、【】（見出しなど）
- **設定**: カッコの種類ごとに「このカッコの声を変える」のオン・オフと、オンのときの **声**（端末の日本語音声）と **声の高さ**。初期値はすべてオフ
- 設定は全作品で共通。作品ごとの設定は持たない
- **速度** はアプリ全体で 1 つ。カッコごとには持たない
- 入口: 設定タブ（§4.14）の「カッコ別の音声」。押すとカッコの種類の一覧を開き、行を押すと、そのカッコの編集画面（全画面）を開く。声の一覧は試聴でき、試聴はそのカッコの高さで鳴らす
- ルール:
  - オンのカッコの中は、そのカッコの声で読む。カッコの記号は読み上げない
  - オフのカッコは本文のまま、外側の声で読む
  - 入れ子にできる（会話の中の『』は『』の声になり、閉じると会話の声に戻る）
  - 同じ段落の中で閉じていないカッコは、カッコとして扱わない
  - 読み方辞書とルビを先に当てる。置換された部分に含まれるカッコは、カッコとして扱わない
  - 読み上げ中の表示は段落単位のまま

### 4.14 設定

種類ごとに見出しを付ける。項目の説明は、項目名の下に小さく薄い文字で出す。スイッチは行のどこを押しても切り替わる。

| グループ | 項目 | 内容 |
| --- | --- | --- |
| 読み上げ | 音声設定 | 今の声と速度を出す。押すと速度・声の高さ・基本音声のページへ（§4.5） |
| | カッコ別の音声 | 声を変えている種類の数、無ければ「オフ」。押すと一覧へ（§4.13） |
| | 読み上げ中は画面を消さない | スイッチ。初期値はオフ。オンのとき、読み上げている間だけ画面の自動消灯を止める。止める・タイマーで止まる・最後まで読むと元に戻る |
| 再生 | 連続再生 | スイッチ。初期値はオン。オフにすると、話の終わりで止まる（§4.7） |
| | 前書き・後書きを読む | スイッチ。初期値はオフ。オンにすると、Web 小説の前書きと後書きも本文と一緒に出して読む（§5） |
| 辞書 | 読み方辞書 | 件数を出す。押すと辞書の一覧へ（§4.6） |
| その他 | ページをめくる音 | スイッチ。初期値はオン（§4.7） |
| バックアップ | バックアップを書き出す | JSON（`soyoli-backup-YYYYMMDD.json`）。保存先のフォルダを選ばせて、そこに保存する |
| | バックアップから取り込む | 確認してから取り込む |
| このアプリについて | バージョン | アプリのバージョンを出す |
| | オープンソースライセンス | 押すと一覧へ |

表示の設定（文字サイズ・行間・テーマ）はリーダー設定（§4.2）にあり、設定タブには置かない。保存容量の表示やキャッシュの削除は設けない（本文を保存しないため）。

**バックアップ（実装済み）**

- **入るもの**: 読み方辞書（割り当てを含む）、音声設定（速度・高さ・基本音声・カッコ別の音声・画面を消さない・ページをめくる音・連続再生・前書き・後書きを読む）、本棚と履歴の Web 小説（メタ情報と最後に読んだ話）、その読みかけの位置
- **入らないもの**: 本文と目次、端末に保存したファイル（EPUB・PDF）とその位置、表示設定、本棚の並び
- **取り込み**: ファイルを選ぶと、何が置き換わり何が加わるかを出して確認する
  - 辞書と音声設定は、バックアップの内容に置き換える。ファイルに入っていない部分は、端末のものを残す
  - Web 小説は本棚と履歴に足す。端末にしかない作品は残る
  - 両方にある作品の読みかけ（最後に読んだ話と位置）は、後に読んだ側のものにする。開いている作品の読みかけは変えない
  - この端末にない声は、端末標準の声にする
- Soyoli のバックアップでないファイル、読めないファイルは、何も変えずに知らせる

**オープンソースライセンス（実装済み）**

- 設定の「オープンソースライセンス」から、アプリが使っているライブラリの一覧を開く。名前の順で、行にはバージョンとライセンスの名前を出す
- 行を押すと、そのライブラリのライセンスの本文（告知のファイルがあればそれも）とページのアドレスを出す。本文を同梱していないライブラリは、ライセンスの名前だけを出す
- 載せるのは、アプリに入って配られるものだけ: JS のバンドルに入るパッケージ（間接の依存も含む）と `package.json` の dependencies、それにネイティブ側だけが入れるライブラリ（Android は Gradle が解決したリリース版の依存、iOS は CocoaPods の Pod）と、表示が条件の素材（ページをめくる音: OtoLogic、CC BY 4.0）。ビルドにしか使わないものは載せない
- Android のライブラリは、同じグループ（`androidx.lifecycle` など）を 1 行にまとめる。Gradle から分かるのはライセンスの名前とページだけなので、本文を付けるのは Apache-2.0 のものだけで、MIT や BSD のものは名前とページを出す
- React Native 本体が中に含めているライブラリ（Folly、Boost など）は、個別には載せない
- 一覧は `assets/licenses.json` としてアプリに同梱する。依存を変えたら `pnpm licenses:update` で作り直す。ネイティブの分は `scripts/native-licenses.json` に持ち、ネイティブの依存が変わったら `pnpm licenses:native` で作り直す

## 5. 横断ルール

- **設定は全作品で共通**: 読み上げと再生の設定は、すべての作品に同じものを使う。作品ごとに持つのは「使う辞書」だけで、作品ごとの設定画面や上書きは設けない
- **本文の取得（Web 小説）**: 本文は保存しない。話を開いたとき、または読み上げがその話へ進んだときに取得する。目次は、ブラウザで話を開いたとき、または目次を持たない作品（起動後に本棚から開いたもの）を開いたときに取得する
  - 先読みはしない。話は、その話に来るたびに取得する。通信できなければ読めない
- **連続再生**: 話の終わりで次の話へ進む。設定でオフにできる（§4.7）。次の話を取得できないときは §4.9
- **前書き・後書き**（Web 小説）: 初期値では読まない（本文に含めない）。設定タブ（§4.14）の「前書き・後書きを読む」をオンにすると、話の題名の次に前書き、本文の後ろに後書きを置き、表示も読み上げもする。前書き・後書きの欄があるのは小説家になろうとハーメルンで、カクヨムにはない。pixiv のキャプションは読まない。切り替えは次に取得する話から効く: 届いている本文は書き換えない（ビューアーの「再取得」で取り直せる）
- **追従スクロール**: 追従している間は読み上げ中の段落が見えるよう自動でスクロールする。手動スクロールでは追従だけを止め、読み上げは継続する（§4.4）
- **データの保持**: 端末に残すのは次のものだけ。キャッシュを削除しても、辞書・読み上げ位置は消さない
  - 取り込んだファイルそのものと表紙、その一覧（書名・著者）
  - Web 小説の、本棚と履歴に載せる作品のメタ情報（書名・著者・サイト）と、最後に読んだ話（題名・URL）、読んだ日時。本文と目次は残さない
  - 作品ごとの読み上げ位置、最後に開いていた作品
  - 読み上げと再生の設定（速度・声の高さ・基本音声・カッコ別の音声・画面を消さない・ページをめくる音・連続再生・前書き・後書きを読む）
  - 読み方辞書（辞書の割り当てと、割り当てた作品の作品名・URL を含む）
  - リーダー設定、本棚の表示（グリッド／リスト）
- **文言**: 画面に出す言葉は次のようにそろえる
  - 元のページへ戻る操作は「元のサイトで開く」（「元サイトで開く」「元サイトを開く」は使わない）
  - データを消す操作は「削除」（本棚から削除／履歴から削除／すべての履歴を削除）。「消す」は入力欄を空にする操作だけに使う
  - 読み上げている場所は「読み上げ位置」（「再生位置」は使わない）
  - 段落メニューから読み始める操作は「ここから読み上げ」
  - 読み上げの最小単位は「段落」（「文」は使わない）
  - 作品内の区切りは「話」（章かどうかは作品によるため、EPUB でも「章」は使わない）
  - 読みを登録する操作と画面は「辞書登録」（「ユーザー辞書」は使わない）
  - 速度・声の高さ・基本音声の設定は「音声設定」（設定タブでも同じ名前）
  - 「ブラウザ」は長音を付けない

## 6. デザイントークン

実装の配色（`src/constants/theme.ts`）。デザインファイルの値（背景 #000000、文字 #FFFFFF など）から、長文を読むアプリとして、まぶしさを抑える方向に変えている。

| トークン | 値 | 用途 |
| --- | --- | --- |
| background | #121214 | 画面背景 |
| surface | #1E1E21 | カード・シート |
| selected | #36363B | 長い一覧の中の「いまの行」（目次の読んでいる話） |
| text | #E8E8EC | 主テキスト |
| secondary | #A0A0A8 | 補助テキスト（読み終えた段落など） |
| border | #3C3C41 | 区切り線 |
| marker | #F2FF4D（不透明度 30%） | 読み上げ中の段落の背景。アプリで唯一の色味 |

- 真っ黒と真っ白は使わない（コントラストは WCAG AAA の 7:1 より上に保つ）。無効の状態は色を足さず、不透明度で示す
- **リーダーのテーマ**（本文の領域だけ）: 黒（上の配色）／セピア（紙 #F4ECD8・文字 #3A2F21）／白（紙 #F7F7F5・文字 #1F1F22）。それぞれに読み終えた段落の色とマーカーの色を持つ
- フォントは端末の標準フォント（デザインファイルの M PLUS 1 Code は使っていない）
- アイコンは Lucide 系の名前（library, home, settings など）で指定し、iOS は SF Symbols、Android は Material Symbols で描く
- 一覧の行・ボタン・スイッチ・スライダー・シートは、できるだけ OS 標準の部品（Expo UI）を使う

## 7. 決めたこと

1. **（決定済み）ビューアーにプレイヤーを常設**: 読む／聴くの入口や画面は分けない（§4.2、§4.7）
2. **（決定済み）段落／話送りに統一**: 話送り・目次・再生は共通の読み上げ位置を更新する
3. **（決定済み）文言のゆれ**: 「ここから読み上げ」にそろえる。「ここから聴く」は使わない。ほかの言い回しは §5「文言」のとおり
4. **（決定済み）アプリの配色はダークだけ**: ライトの配色と「端末に合わせる」は設けない。本文の領域だけは、リーダーのテーマで明るい紙を選べる
5. **（決定済み）作らないもの**: 音声プロファイル、作品設定と作品ごとの上書き、作品の追加シート、取得状態つきの目次、先読み、本棚の並べ替え、取得失敗のアラート

## 8. 実装の現状と制約

Expo SDK 58。AGENTS.md の方針に従い、Expo の API に触れる前に該当バージョンのドキュメントで確認すること。

- **読み上げ**: `expo-speech`（端末内蔵の音声）。段落ごとに読み、カッコ別の音声では 1 つの段落を声ごとの区間に分けて順に読む。一時停止は「止めて、再開時にその段落の先頭から読み直す」（Android に途中からの再開が無いため）
- **バックグラウンド再生とロック画面の操作**: iOS は `UIBackgroundModes: audio`、ロック画面・通知の操作は `expo-media-control`。Expo Go では動かず、development build が必要
- **音声の追加**: アプリからは追加できない。端末の読み上げ設定へ案内する
- **EPUB**: アプリ内で展開して解析する（`fflate`＋`fast-xml-parser`）。出版社のスタイルは捨て、本文・ルビ・挿絵だけを取り出す
- **PDF**: 端末の仕組みで本文を抜き出す自前のモジュール `modules/pdf-text`（§4.1）
- **Web 小説**: 各サイトのページの HTML を解析して、本文と目次を取り出す（公開の API は使っていない。pixiv だけは、ページが読む JSON を読む: §4.10）。サイトごとの違いは `src/features/web/sites/` にまとめてある。サイトの構造が変わると読めなくなる。各サイトの利用規約の確認は別途必要
- **しないこと**: 電話などで音声が中断されたあとの自動再開、オフラインでの Web 小説の再生（本文を保存しないため）
